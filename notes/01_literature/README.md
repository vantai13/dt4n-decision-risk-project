# Literature

Workbook chính thức duy nhất: `novelty_matrix.xlsx`
(sheet `Novelty Matrix`, `All Papers Comparison` và các sheet phân tích từng paper).

Đây là tài liệu SỐNG: sửa trực tiếp, git quản lý phiên bản. Không đưa phiên bản vào tên file.
Khi cần đóng băng một phiên bản làm căn cứ (ví dụ tại DP1), gắn git tag.

Ghi chú từng paper có thể đặt thêm tại đây (một file/paper nếu cần).
Không lưu PDF có bản quyền vào git; chỉ lưu ghi chú + link/DOI.
