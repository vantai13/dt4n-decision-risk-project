# Bài học mang theo từ dt4n (giữ ngắn)

Giữ:
1. Trước khi đổ lỗi cho code, suy ràng buộc từ định luật (NT 49).
2. Bench trước, wire sau: cái gì kiểm được bằng NumPy thì kiểm bằng NumPy trước (NT 52).
3. Một thí nghiệm, một loại câu hỏi (NT 55).
4. Gate TÍNH HỢP LỆ tách khỏi KẾT QUẢ; kết quả âm có kiểm soát vẫn là dữ liệu (NT 56).

Không lặp lại:
- Quy trình phình to hơn câu hỏi khoa học (hàng trăm gate/amendment cho một paper).
- Ép Mininet làm bộ sinh tải có kiểm soát.
- Đặt tên thư mục trùng package hệ thống (`mininet/`).

Vệ sinh tối thiểu cho mỗi kết quả: seed + config + git hash + một dòng dự đoán viết trước.
